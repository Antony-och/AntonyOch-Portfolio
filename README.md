# Antony Onyi Portfolio

A modern portfolio website for Antony Onyi, showcasing technical skills, recent projects, and contact information.

## Overview

This project is a single-page portfolio built with HTML, CSS, and JavaScript. It is designed to feel premium and minimal, with a dark glassmorphism aesthetic, animated hero text, smooth reveal effects, and responsive layout for desktop and mobile devices.

## Features

- Elegant dark-themed design
- Fixed navigation with mobile menu
- Typewriter-style hero text
- Services section
- About section with stats
- Skills grid with technology highlights
- Project showcase cards with live links
- Contact form integration
- Responsive layout for various screen sizes

## Project structure

- `index.html` — main portfolio page and styling
- `assets/` — downloadable assets such as CV/resume
- `img/` — images and branding assets
